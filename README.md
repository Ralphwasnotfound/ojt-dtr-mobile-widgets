# BSIT-TCC OJT Monitoring & DTR — Native Mobile Applications

This repository contains the native mobile applications for the BSIT-TCC OJT
Monitoring & DTR System at Torres Capitol College.

- `ANDROID/` — the Kotlin / Jetpack Compose Android application, including the
  U7.5B secure Supabase authentication foundation.
- `IOS/` — the future native Swift iOS application.

See `ANDROID/README.md` for Android setup, client configuration, build commands,
and verification. The existing Vue web application is maintained in a separate
repository. No attendance features, widgets, or iOS application are implemented
by this checkpoint. U7.5C has not started.

Local configuration, credentials, signing material, IDE state, and generated
build outputs must remain untracked.
